- [ ] **Step 6: 实现 OnDutyClient**

`OnDutyClient.java`:
```java
@Component
public class OnDutyClient {
  private static final Logger log = LoggerFactory.getLogger(OnDutyClient.class);
  private final RestClient.Builder builder; // 注入,便于测试替换 requestFactory

  public OnDutyClient(RestClient.Builder builder) { this.builder = builder; }

  @JsonIgnoreProperties(ignoreUnknown = true)
  record ExternalUser(String nickname, String phone) {}

  public Optional<OnDutyPerson> primaryByScheduleName(String baseUrl, String apiKey, String scheduleName) {
    if (baseUrl == null || baseUrl.isBlank() || apiKey == null || apiKey.isBlank()
        || scheduleName == null || scheduleName.isBlank()) return Optional.empty();
    try {
      RestClient client = builder.clone()
          .requestFactory(timeoutFactory()) // connect/read ~3s
          .build();
      ExternalUser[] users = client.get()
          .uri(baseUrl + "/api/external/on-duty?scheduleName={n}", scheduleName)
          .header("Authorization", "Bearer " + apiKey)
          .retrieve()
          .body(ExternalUser[].class);
      if (users == null || users.length == 0) return Optional.empty();
      ExternalUser u = users[0];
      if (u == null || u.phone() == null) return Optional.empty();
      return Optional.of(new OnDutyPerson(u.nickname(), u.phone()));
    } catch (Exception e) {
      log.warn("on-duty lookup failed for schedule {}: {}", scheduleName, e.toString());
      return Optional.empty();
    }
  }

  private ClientHttpRequestFactory timeoutFactory() {
    SimpleClientHttpRequestFactory f = new SimpleClientHttpRequestFactory();
    f.setConnectTimeout(3000); f.setReadTimeout(3000);
    return f;
  }
}
```
(测试中通过 `MockRestServiceServer.bindTo(builder)` 注入的 builder 验证;若 requestFactory 替换导致 mock 失效,则在测试用单独构造 —— 实现时确保测试可注入。可将 RestClient 构造提取为可重写方法以便测试 stub。)
Run: `mvn -q -Dtest=OnDutyClientTest test` → 绿。

- [ ] **Step 7: 写 OnDutyCache**

`OnDutyCache.java`:
```java
@Component
public class OnDutyCache {
  private record Entry(Optional<OnDutyPerson> value, Instant expiresAt) {}
  private static final Duration TTL = Duration.ofMinutes(10);
  private final Map<String, Entry> cache = new ConcurrentHashMap<>();
  private final Clock clock;
  private final OnDutyClient client;
  public OnDutyCache(Clock clock, OnDutyClient client) { this.clock = clock; this.client = client; }

  public Optional<OnDutyPerson> get(String baseUrl, String apiKey, String scheduleName) {
    Instant now = clock.instant();
    Entry e = cache.get(scheduleName);
    if (e != null && e.expiresAt().isAfter(now)) return e.value();
    Optional<OnDutyPerson> fresh = client.primaryByScheduleName(baseUrl, apiKey, scheduleName);
    cache.put(scheduleName, new Entry(fresh, now.plus(TTL)));
    return fresh;
  }
}
```
