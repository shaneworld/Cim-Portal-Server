# 公告 + 收藏(我的链接)设计

**日期:** 2026-06-11 **状态:** 设计已确认,进入实现计划
**仓库:** 后端 `cim-portal-server`(Oracle/JDK21/Flyway/JPA)+ 前端 `cim-portal-client`(Vue3/TS/Tailwind v3/vue-i18n/Pinia),分支 `dev`。两功能独立,顺序 ①公告 → ②收藏,各自提交。

## 已确认决策
- 公告受众:**v1 面向所有登录用户**(不做部门/角色/组定向)。
- 已读/忽略:**前端 localStorage 忽略**(无服务端已读表)。
- 公告正文:**纯文本**(保留换行)。
- 收藏范围:**仅可访问链接**可收藏(服务端强制)。
- 收藏排序:v1 不支持(YAGNI)。

## 现状(已核对)
- `HomeController GET /api/portal/home` → `HomeService.resolveFor(CurrentUser)` → `HomeResponse{categories:[HomeCategory{categoryCode,labelZh,labelEn,links:[HomeLink]}]}`。`HomeLink(id,nameZh,nameEn,url,icon,statusCode,openInNewTab,environment,launchApp,downloadUrl,accessible)`。
- `CurrentUser(employeeId, departmentCode, roleCode, admin)`;`CurrentUserService` 提供之。`PermissionResolver.isVisible(dept,role,Set<groupCodes>,grants)` 判定可访问(无 grant=所有人)。
- 前端 `HomeView.vue`:`AppHeader → HeroPanel → GlobalSearch → SystemGrid(:categories=filtered)`;`SystemCard.vue` 渲染单链接卡(图标方块 + 中/英名 + 环境 pill + 锁定态)。
- 管理 CRUD 范式:`/api/admin/*`(`hasRole(PORTAL_ADMIN)`),前端 `src/features/admin/{enums,groups,...}` 列表 + 弹窗;admin 导航在 `AdminLayout.vue`,路由 `src/router/index.ts`。
- i18n `src/lib/i18n/locales/{zh,en}.ts` + 键对齐 `i18n.spec.ts`。测试基类 `OracleIntegrationTest` + `TestJwts.bearerFor(empId)`。Flyway oracle 最新 **V8**(下一个 V9、V10)。`OracleMigrationTest` 断言 8。

## ① 公告(Announcements)

### 数据模型(Flyway **V9**)
```sql
CREATE TABLE announcement (
  id         NUMBER GENERATED BY DEFAULT AS IDENTITY (START WITH 1000),
  title_zh   VARCHAR2(255) NOT NULL,
  title_en   VARCHAR2(255) NOT NULL,
  body_zh    CLOB          NOT NULL,
  body_en    CLOB          NOT NULL,
  level      VARCHAR2(16)  DEFAULT 'INFO' NOT NULL,   -- INFO | MAINTENANCE | OUTAGE
  pinned     NUMBER(1)     DEFAULT 0 NOT NULL,
  starts_at  TIMESTAMP     NULL,
  ends_at    TIMESTAMP     NULL,
  active     NUMBER(1)     DEFAULT 1 NOT NULL,
  created_at TIMESTAMP     DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT pk_announcement PRIMARY KEY (id)
);
```

### 后端
- `Announcement` 实体(`@Lob String bodyZh/bodyEn`)+ `AnnouncementLevel` 枚举 `{INFO, MAINTENANCE, OUTAGE}` + `AnnouncementRepository`。
- `AnnouncementService`:
  - 管理:list(全部,按 pinned desc, created_at desc)、get、create、update、delete。
  - 门户:`effective()` → `active=true 且 (starts_at 为空或 ≤ now) 且 (ends_at 为空或 ≥ now)`,排序 pinned desc, created_at desc。
- 管理 API `/api/admin/announcements`(PORTAL_ADMIN):GET 列表、POST、GET/{id}、PUT/{id}、DELETE/{id}。`AnnouncementRequest(titleZh,titleEn,bodyZh,bodyEn,level,pinned,startsAt?,endsAt?,active)`、`AnnouncementResponse(id,...,createdAt)`。
- 门户 API `GET /api/portal/announcements`(任意登录用户)→ `List<AnnouncementResponse>`(仅 effective)。

### 前端
- API client:`portal.listAnnouncements()`;admin `announcements`(list/get/create/update/delete)。
- `AnnouncementsPanel.vue`(放 `HomeView` 的 `HeroPanel` 之后):拉 effective 列表;按 level 着色(INFO 蓝 / MAINTENANCE 琥珀 / OUTAGE 红)+ 图标;`OUTAGE` 或 `pinned` 渲染为醒目横幅,其余为紧凑卡片;正文 `whitespace-pre-line`(保留换行);每条可**忽略(×)**——把 id 存入 `localStorage`(键 `cim.dismissedAnnouncements`),已忽略的不再显示。无 effective 或全部被忽略 → 不渲染。
- `AnnouncementsAdminView.vue` + `AnnouncementFormModal.vue`(列:标题、level、pinned、生效窗口、active、操作;表单:中/英标题、中/英正文 textarea、level 选择、pinned/active 开关、可选起止时间);加入 admin 导航 + 路由。
- i18n zh/en 键(对齐)。

### 测试
- 后端:管理 CRUD;门户 effective 过滤与排序(active=0、未到 starts_at、已过 ends_at 不返回;pinned 置顶)集成(`OracleIntegrationTest`+`TestJwts`)。`OracleMigrationTest` 8→**9**。
- 前端:i18n 对齐;`AnnouncementsPanel` 忽略(localStorage)行为测试。

## ② 收藏 / 我的链接(Favorites)

### 数据模型(Flyway **V10**)
```sql
CREATE TABLE favorite (
  employee_id VARCHAR2(64) NOT NULL,
  link_id     NUMBER       NOT NULL,
  created_at  TIMESTAMP    DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT pk_favorite PRIMARY KEY (employee_id, link_id),
  CONSTRAINT fk_favorite_link FOREIGN KEY (link_id) REFERENCES link(id) ON DELETE CASCADE
);
```

### 后端
- `Favorite` 实体(复合主键 `@IdClass`)+ `FavoriteRepository`(`findLinkIdsByEmployeeId`、`existsBy...`、`deleteBy...`)。
- `HomeLink` DTO 增 `boolean favorite`;`HomeService.resolveFor` 先取当前用户收藏 link-id 集合,逐链接设 `favorite`(仅对 accessible 链接有意义,UI 仅在可访问卡显示星)。
- `FavoriteController`(任意登录用户,非 admin):`POST /api/portal/favorites/{linkId}`(收藏)、`DELETE /api/portal/favorites/{linkId}`(取消)。**仅可访问**:POST 时用 `PermissionResolver` + 用户组 code 校验该链接对当前用户可访问,否则 403。
- 不新增「列出收藏」端点 —— 前端从 `categories` 中 `favorite=true` 的链接聚合「我的收藏」。

### 前端
- `SystemCard.vue`:可访问卡右上角加**星标切换**(乐观更新,调 toggleFavorite)。锁定卡不显示星。
- `HomeView.vue`:在 `SystemGrid` 之上加「**我的收藏 / My links**」区,聚合所有 `favorite=true` 的可访问链接(无则不显示)。
- API client:`toggleFavorite(linkId, on)`(on→POST,off→DELETE)。i18n zh/en 键。

### 测试
- 后端:收藏/取消;对锁定(无权)链接 POST → 403;`HomeLink.favorite` 标记集成。`OracleMigrationTest` 9→**10**。
- 前端:i18n 对齐;`SystemCard` 星标切换测试。
