## ① 权限组(后端 + 前端)

### 现状(保持不变)
- `link_access_grant(id, link_id, grant_type ∈ {DEPARTMENT,ROLE}, grant_code)`,FK→`link(id)` ON DELETE CASCADE,唯一 `(link_id,grant_type,grant_code)`。
- `PermissionResolver.isVisible(departmentCode, roleCode, grants)`:**无 grant → 所有人可见**;否则按用户 dept/role 做 OR 匹配。
- `HomeService`:逐链接算 `accessible`,不可见时把 `url/downloadUrl` 置 null(锁定卡片)。
- `UserInfo`:单一 `department_code` + `role_code`。已知角色含 `PORTAL_ADMIN`。
- 链接授权 API:`GET/POST/PUT/DELETE /api/admin/links/{id}/grants`(`GrantRequest{grantType,grantCode}`,PUT 整体替换)。
- 测试基类 `OracleIntegrationTest`;`TestJwts.bearerFor(employeeId)` 造 token;`OracleMigrationTest` 断言迁移数=6。

### 数据模型(Flyway **V7**,oracle)
```sql
CREATE TABLE permission_group (
  id         NUMBER GENERATED BY DEFAULT AS IDENTITY (START WITH 1000),
  code       VARCHAR2(64)  NOT NULL,
  name_zh    VARCHAR2(255) NOT NULL,
  name_en    VARCHAR2(255) NOT NULL,
  active     NUMBER(1)     DEFAULT 1 NOT NULL,
  created_at TIMESTAMP     DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT pk_perm_group PRIMARY KEY (id),
  CONSTRAINT uk_perm_group_code UNIQUE (code)
);
CREATE TABLE permission_group_member (
  group_id    NUMBER       NOT NULL,
  employee_id VARCHAR2(64) NOT NULL,
  CONSTRAINT pk_pg_member PRIMARY KEY (group_id, employee_id),
  CONSTRAINT fk_pg_member_group FOREIGN KEY (group_id)
      REFERENCES permission_group(id) ON DELETE CASCADE
);
```
- `GrantType` 增加枚举值 **`GROUP`**;`link_access_grant` 结构不变,GROUP 授权的 `grant_code` = 组的 `code`。
- 成员 `employee_id` 不设到 `user_info` 的硬 FK(成员可能由 SSO 后续置备)。

### 解析逻辑(唯一的算法改动)
`PermissionResolver.isVisible(departmentCode, roleCode, Set<String> userGroupCodes, grants)`:无 grant → true;否则逐 grant:`DEPARTMENT==dept` ∨ `ROLE==role` ∨ `GROUP 且 grant_code ∈ userGroupCodes` → true。
`HomeService` 先查当前用户的组 code 集合(按 employee_id),传入解析。锁定卡片行为不变(组只会扩大可见范围)。

### 后端组件
- 实体/仓库:`PermissionGroup` + `PermissionGroupRepository`;`PermissionGroupMember`(`@IdClass`/复合主键)+ 仓库(`findGroupCodesByEmployeeId`、`findByGroupId`、按 group 批量删/插)。
- `PermissionGroupService`:组 CRUD(创建校验 code 唯一)、列表、成员查询/整体替换。
- 管理 API `@RequestMapping("/api/admin/permission-groups")`(`PORTAL_ADMIN`):
  - `GET /`、`POST /`(`{code,nameZh,nameEn,active}`)、`GET /{id}`、`PUT /{id}`、`DELETE /{id}`
  - `GET /{id}/members` → `List<String> employeeIds`;`PUT /{id}/members`(`{employeeIds:[...]}` 整体替换)
- 授权校验:`LinkService` 校验 grant_code 时,`GROUP` 类型须存在且 active 的组(DEPT/ROLE 仍校验 `enum_value`)。
- 分配组到链接:**复用现有 `/grants` API**,`grantType=GROUP`,无新端点。

### 前端
- 新管理页 **「权限组 / Permission Groups」**(加入 admin 导航):组列表、创建/编辑(code、中英文名、启用)、成员管理(从现有用户列表多选 employee_id;复用用户 API)。
- 链接表单授权区:类型下拉新增 `GROUP`,选中时 code 下拉列出权限组(拉 `/api/admin/permission-groups`)。其余沿用现有 grant 行 UI。
- API client 方法 + zh/en i18n 键(保持 `i18n.spec.ts` 键对齐)。

### 测试
- 后端:权限组 CRUD + 成员替换控制器测试(`OracleIntegrationTest` + `TestJwts`);`PermissionResolver` 单测覆盖 GROUP 命中/未命中;`HomeService` 集成(组成员可见、非成员锁定);`OracleMigrationTest` 期望数 6→**7**。
- 前端:i18n 键对齐;权限组页轻量组件测试(可选)。

## ② 响应式配置弹窗

### 现状
共享 `src/lib/ui/Modal.vue` 容器类:`w-full max-w-lg ... max-h-[85vh] overflow-y-auto`。`max-w-lg`(512px)导致**窄而高**。配置弹窗:`LinkFormModal.vue`、`EnumFormModal.vue`、`ConfirmDialog.vue`(均基于 Modal);`SecurityAdminView.vue` 为整页非弹窗(本任务不改其结构,仅可顺带放宽 `max-w-lg`)。表单已用 `grid grid-cols-1 sm:grid-cols-2`。

### 设计
- `Modal.vue` 增加 `size` prop:`'sm'|'md'|'lg'|'xl'` → 最大宽 `28 / 36 / 48 / 60rem`(默认 `md`)。容器宽度改为 `w-[min(92vw,<max>)]`,高度 `max-h-[90vh] overflow-y-auto`。→ **随窗口缩放实时自适应,移动端由 92vw 钳制**,无 JS。
- 各弹窗指定 size:`LinkFormModal` = `xl`(字段多 + 图标网格),`EnumFormModal` = `md`,`ConfirmDialog` = `sm`。
- 宽度变大后现有 `sm:grid-cols-2` 网格得以并排,消除“窄高”。验证小屏不溢出、滚动正常。
- 测试:`Modal` size prop 渲染类正确(组件测试);手动/截图验证缩放自适应。

## ③ 全局字体(Inter + MiSans,自托管)

### 现状
无任何自定义字体:`tailwind.config.js` 无 `fontFamily`;`index.html` / `src/assets/index.css` 不加载字体;`body` 无 `font-family`。

### 设计
- 自托管 **woff2** 子集到 `src/assets/fonts/`:Inter(400/500/600/700,拉丁)+ MiSans SC(400/500/600,中文)。Inter 取自 `@fontsource/inter` 静态 woff2;MiSans 取自其官方免费授权发布(woff2)。
- `@font-face`(`font-display: swap`)写入字体样式(`src/assets/fonts.css` 或 `index.css`)。
- Tailwind `theme.extend.fontFamily.sans = ['Inter','MiSans','system-ui','-apple-system','PingFang SC','Microsoft YaHei','sans-serif']`(拉丁走 Inter,CJK 落到 MiSans,加载中用系统字体兜底)。
- 全局应用:`body { font-family: theme(fontFamily.sans); -webkit-font-smoothing: antialiased; }`;标题按需加重字重。
- **交付含实时预览**:构建/运行后截图 登录页 / 首页 / 一个管理弹窗 展示新字体,经确认后定稿。
- 授权:Inter = SIL OFL;MiSans = 免费商用。体积:CJK 数 MB,内网缓存可接受,`font-display: swap` 不阻塞首屏。
- 测试:构建通过;视觉(截图)验证。
