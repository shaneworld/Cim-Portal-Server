# 首页增强:欢迎面板精简 + 公告(可配置类型/开关)+ 值班电话 + 收藏 设计

**日期:** 2026-06-11 **状态:** 设计已确认(含 mockup `/home/shane/cim-dashboard-v2-mock.png`),进入实现计划
**仓库:** 后端 `cim-portal-server` + 前端 `cim-portal-client`,分支 `dev`。
> 取代早前的「公告+收藏」设计 —— 范围扩展为四块,顺序 A→B→C→D,各自提交。

## 已确认决策
- 欢迎面板:**自适应** —— 当公告或值班面板**任一启用**(出现信息行)时,切换为 mockup 的紧凑单行;两者都关时,**保持现有尺寸与设计不变**。
- 公告类型:**后台可管理的类型清单**(每类型含 颜色 + 图标),非固定枚举。
- 公告开关:**管理员可全局启用/停用**;停用则首页不渲染公告区(且不请求)。
- 公告展示:**单一面板**,逐条按其类型的颜色/图标着色;置顶优先;前端 localStorage 忽略;正文纯文本。
- 值班电话:后台可管理(中/英名 + 号码 + 排序 + 启用);**管理员可全局启用/停用**(与公告并列两个开关);启用且有 active 数据时才在首页右侧显示。
- 收藏:仅可访问链接可收藏;无排序(沿用早前设计)。
- **环境指示器:`SystemCard` 的环境徽标(DEV/UAT/RELEASE,现有 `LINK_ENVS` 彩点设计)保持不变**(mockup 中的简化样式仅示意);收藏只新增星标,不动环境徽标。

## 现状(已核对)
- 首页 `HomeView.vue`:`AppHeader → HeroPanel → GlobalSearch → SystemGrid`。`HeroPanel.vue` 现为 GlassCard 双列(1.1fr/1fr):左 LIVE+问候+部门·角色·工号+时钟,右 3 个大数字统计(text-3xl)。
- `HomeController GET /api/portal/home` → `HomeService.resolveFor(CurrentUser)`;`HomeLink` record(末尾将加 `favorite`)。`CurrentUser(employeeId,departmentCode,roleCode,admin)`;`PermissionResolver.isVisible(dept,role,Set<groupCodes>,grants)`。
- 设置单例 `security_setting`(SSO 配置)经 `PublicConfig`(`/api/portal/config`,permitAll)暴露给前端;`SecuritySettingUpdateRequest`/`AdminSettingView`/`SecuritySettingAdminController(/api/admin/security-settings)`;前端 `SecurityAdminView.vue`。
- enum_value 无 color/icon 字段。`iconMap`/`AppIcon` 已有 lucide 图标体系(可复用图标 key)。
- 管理 CRUD 范式:`/api/admin/*`(PORTAL_ADMIN),前端 `features/admin/*` 列表+弹窗;导航 `AdminLayout.vue`;路由 `router/index.ts`。i18n `locales/{zh,en}.ts` + 对齐测试。`OracleIntegrationTest`+`TestJwts`;Flyway oracle 最新 **V8**;`OracleMigrationTest` 断言 8。

## A. 欢迎面板(自适应,前端)
`HeroPanel.vue` **保留现有布局为默认(展开)态**;新增 `compact` prop:为真时渲染 mockup 的紧凑单行(LIVE 徽标 + 问候(+姓名)+「部门 · 角色 · 工号」+ 时钟;右侧 3 个**小号**统计磁贴 ~text-xl;降低内边距/高度)。`HomeView` 传入 `:compact="config.announcementsEnabled || config.dutyLinesEnabled"`。即:公告/值班任一开启 → 紧凑;两者都关 → 现有尺寸与设计不变。两态共用现有数据源(props.categories、useClock、auth),保持玻璃风。无后端改动。测试:`HeroPanel.spec.ts` 覆盖两态(compact 真/假渲染差异 + 统计值仍在)。

## B. 公告(可配置类型 + 全局开关 + 单面板)

### 数据模型(Flyway **V9**:类型表 + 公告表 + 设置列 + 种子)
```sql
CREATE TABLE announcement_type (
  id        NUMBER GENERATED BY DEFAULT AS IDENTITY (START WITH 1000),
  code      VARCHAR2(64)  NOT NULL,
  label_zh  VARCHAR2(255) NOT NULL,
  label_en  VARCHAR2(255) NOT NULL,
  color     VARCHAR2(16)  DEFAULT 'blue' NOT NULL,   -- 调色板键:blue|amber|red|green|purple|slate
  icon      VARCHAR2(64)  DEFAULT 'info' NOT NULL,   -- lucide 图标 key
  sort_order NUMBER       DEFAULT 100 NOT NULL,
  active    NUMBER(1)     DEFAULT 1 NOT NULL,
  CONSTRAINT pk_ann_type PRIMARY KEY (id),
  CONSTRAINT uk_ann_type_code UNIQUE (code)
);
CREATE TABLE announcement (
  id         NUMBER GENERATED BY DEFAULT AS IDENTITY (START WITH 1000),
  title_zh   VARCHAR2(255) NOT NULL,
  title_en   VARCHAR2(255) NOT NULL,
  body_zh    CLOB          NOT NULL,
  body_en    CLOB          NOT NULL,
  type_code  VARCHAR2(64)  NOT NULL,   -- 引用 announcement_type.code
  pinned     NUMBER(1)     DEFAULT 0 NOT NULL,
  starts_at  TIMESTAMP     NULL,
  ends_at    TIMESTAMP     NULL,
  active     NUMBER(1)     DEFAULT 1 NOT NULL,
  created_at TIMESTAMP     DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT pk_announcement PRIMARY KEY (id)
);
ALTER TABLE security_setting ADD (announcements_enabled NUMBER(1) DEFAULT 1 NOT NULL);
-- 种子默认类型(保证开箱可用)
INSERT INTO announcement_type (code,label_zh,label_en,color,icon,sort_order) VALUES ('INFO','通知','Info','blue','info',10);
INSERT INTO announcement_type (code,label_zh,label_en,color,icon,sort_order) VALUES ('MAINTENANCE','维护','Maintenance','amber','wrench',20);
INSERT INTO announcement_type (code,label_zh,label_en,color,icon,sort_order) VALUES ('OUTAGE','停机','Outage','red','triangle-alert',30);
```
> `color` 用调色板键(前端映射到 Tailwind 类,避免任意 hex 被 purge);`icon` 为 lucide key(前端经 `AppIcon`/iconMap 渲染,未知则回退)。颜色调色板键集合在前后端各有一份常量。

### 后端
- `AnnouncementType` 实体 + 仓库(`findByCodeAndActiveTrue`、`existsByCode`、`findAllByOrderBySortOrderAsc`);`AnnouncementTypeService` + 管理 `/api/admin/announcement-types`(CRUD,创建校验 code 唯一 + color 在调色板内;被公告引用的类型不可硬删——拒绝或仅停用)。
- `Announcement` 实体(`@Lob` 正文)+ 仓库 + `AnnouncementService`:管理 CRUD(创建/改时校验 `type_code` 存在且 active);`effective(now)`(active 且在生效窗口,排序 pinned desc, created_at desc)。
- 管理 `/api/admin/announcements`(CRUD);门户 `GET /api/portal/announcements`(登录用户,返回 effective)。
- **开关**:`security_setting.announcements_enabled` → 加入 `PublicConfig`(`announcementsEnabled`)+ `AdminSettingView` + `SecuritySettingUpdateRequest`;`SecuritySettingService` 处理。门户 `/api/portal/config` 暴露之。
- 门户 `AnnouncementResponse` **内联类型样式**(`typeColor`/`typeIcon`/`typeLabelZh`/`typeLabelEn`,服务端按 type_code join 类型),前端无需单独取类型表。

### 前端
- API:`getConfig()`(加 `announcementsEnabled`)、`listAnnouncements()`;admin `announcements` + `announcementTypes` CRUD。
- `AnnouncementsPanel.vue`(`HeroPanel` 之后):仅当 `config.announcementsEnabled` 为真才请求+渲染;拉 effective;**单卡**列出,逐条按 `typeColor` 着色(调色板键→Tailwind 类 map)+ `typeIcon`(AppIcon);置顶项带 pin 且排前;每条 × 忽略(localStorage `cim.dismissedAnnouncements`);正文 `whitespace-pre-line`。全部被忽略/无 effective → 不渲染。
- 管理:`AnnouncementsAdminView` + 表单(标题/正文 zh-en、类型 Select(来自类型清单)、pinned、active、起止时间)+ 顶部「公告功能 开/关」Switch(调 security-settings PUT 的 `announcementsEnabled`);`AnnouncementTypesAdminView` + 表单(code、zh/en 名、颜色 Select(调色板)、图标 picker(复用图标网格)、排序、active)。导航 + 路由 + i18n(对齐)。

### 测试
- 后端:类型 CRUD + 唯一/校验;公告 CRUD + 无效 type_code 拒绝;effective 过滤/排序;config 含 `announcementsEnabled` 且 PUT 可改。`OracleMigrationTest` 8→**9**。
- 前端:i18n 对齐;`AnnouncementsPanel` 在 `announcementsEnabled=false` 不渲染、忽略行为;颜色映射。

## C. 值班电话(Duty Lines)

### 数据模型(Flyway **V10**)
```sql
CREATE TABLE duty_line (
  id        NUMBER GENERATED BY DEFAULT AS IDENTITY (START WITH 1000),
  label_zh  VARCHAR2(255) NOT NULL,
  label_en  VARCHAR2(255) NOT NULL,
  phone     VARCHAR2(64)  NOT NULL,
  sort_order NUMBER       DEFAULT 100 NOT NULL,
  active    NUMBER(1)     DEFAULT 1 NOT NULL,
  CONSTRAINT pk_duty_line PRIMARY KEY (id)
);
ALTER TABLE security_setting ADD (duty_lines_enabled NUMBER(1) DEFAULT 1 NOT NULL);
```
### 后端
- `DutyLine` 实体 + 仓库(`findByActiveTrueOrderBySortOrderAsc`)+ 服务;管理 `/api/admin/duty-lines`(CRUD);门户 `GET /api/portal/duty-lines`(登录用户,仅 active,按 sort)。
- **开关**:`security_setting.duty_lines_enabled` → `PublicConfig` + `AdminSettingView` + `SecuritySettingUpdateRequest` 各加 `dutyLinesEnabled`(与 `announcementsEnabled` 并列)。
### 前端
- `DutyLinesPanel.vue`:首页右侧(与公告同一行;mockup 布局 `grid-cols-[1.95fr_1fr]`,移动端堆叠);**仅当 `config.dutyLinesEnabled` 为真才请求+渲染**,且列表为空时不渲染;每行 电话图标 + 中/英名 + 号码。
- 管理:`DutyLinesAdminView` + 表单(zh/en 名、号码、排序、active)+ 顶部「值班电话功能 开/关」Switch(写 security-settings 的 `dutyLinesEnabled`)+ 导航/路由 + i18n。
### 测试
- 后端:CRUD + 门户仅 active/排序。`OracleMigrationTest` 9→**10**。前端:i18n 对齐 + 空列表不渲染。
