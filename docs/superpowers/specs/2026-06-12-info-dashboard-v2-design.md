# 信息仪表盘 v2:公告高度 / 快捷链接 / 间距 / 值班外部 API 设计

> 日期:2026-06-12。范围:首页信息栏(infoPanel)四项改进。后端 Oracle-only,Spring Boot 3.3/JDK 21;前端 Vue 3 + TS。沿用既有 duty-line / favorite 模块模式。

## 背景与目标

首页信息栏当前含「公告(Announcements)」+「值班电话(Duty Lines)」两块(由 `info_panel_enabled` 统一开关)。本轮四项改进:

1. **公告面板高度封顶** —— 公告随条数无限增高,改为定高 + 内部滚动。
2. **新增「快捷链接(Quick Links)」面板** —— 管理员配置的全局自由 URL 列表(label + URL + icon),所有用户可见、便捷访问。与「我的收藏 / My links」(按用户、收藏门户系统)是不同概念。
3. **缩小面板间距** —— 整体纵向间距过宽,收紧使布局更平衡。
4. **值班电话改为对接外部值班管理系统 API** —— 按管理员为每条值班配置的「排班名称(section code)」实时拉取当日值班人(姓名 + 电话);外部 API base URL + key 由管理员在 UI 配置,后端代理,密钥不出后端。

## 硬约束

- `mvn test` 全绿;`OracleMigrationTest` 断言迁移数 12→**15**(V14、V15 两条新迁移;当前最高 V13)。
- i18n zh/en 对齐(`i18n.spec.ts` 绿)。
- 向后兼容:`/api/portal/config` 不变;新增端点不破坏既有。
- 外部 API key **绝不**下发到浏览器;读取时掩码。
- 外部 API 不可用时,值班面板优雅降级到静态 label/phone,不报错阻塞。

## #4 值班电话对接外部值班管理系统 API

### 外部 API 契约(给定)

- `GET {baseUrl}/api/external/on-duty`,Header `Authorization: Bearer <api-key>`。
- 查询参数(三选一):`scheduleName`(= 用户的 section code,本项目采用此项)/ `scheduleId` / `departmentId`。
- 返回:`User[]`,每个 user 形如
  ```json
  [{"id":49954,"username":"E0026701","nickname":"韩逸水","role":"IT","email":"...","phone":"16601822375","gender":"FEMALE",...,"reportTo":{...},"department":{...},"active":true}]
  ```
  本项目只取**首个**元素的 `nickname`(姓名)+ `phone`(电话)。

### 后端

- **迁移 V15** `db/migration/oracle/V15__duty_external.sql`:
  ```sql
  ALTER TABLE duty_line ADD (schedule_name VARCHAR2(255));
  ALTER TABLE security_setting ADD (
    duty_api_base_url VARCHAR2(512),
    duty_api_key      VARCHAR2(512)
  );
  ```
  `schedule_name` 可空(空 = 该条仍用静态电话)。
- **`DutyLine` entity** 加 `String scheduleName`(nullable)+ getter/setter;`DutyLineRequest`/`DutyLineResponse` 加 `scheduleName`;Service create/update/map 处理。
- **`SecuritySetting`** 加 `dutyApiBaseUrl`、`dutyApiKey`(String,nullable)。
  - `AdminSettingView`:含 `dutyApiBaseUrl`;**`dutyApiKey` 掩码**——返回布尔 `dutyApiKeyConfigured`(是否已设)或固定掩码串,不回传明文。
  - `SecuritySettingUpdateRequest`:含 `dutyApiBaseUrl`、`dutyApiKey`(若请求 `dutyApiKey` 为 null/未传则保留原值,空串可视为清除——实现时明确取「未传=保留」)。
  - `PublicConfig` **不含**这两项(密钥不下发)。
- **外部调用客户端** `com.cimportal.dutyline.OnDutyClient`:
  - 用 Spring 6 `RestClient`(由 `spring-boot-starter-web` 提供;以 `RestClient.builder()` 构造,base URL 与 key 在调用时从 `SecuritySetting` 读取,而非启动期 bean 固化——因为可在 UI 改)。
  - 方法 `Optional<OnDutyPerson> primaryByScheduleName(String baseUrl, String apiKey, String scheduleName)`:GET `{baseUrl}/api/external/on-duty?scheduleName=...`,Bearer key,解析数组取首个 → `OnDutyPerson(name=nickname, phone=phone)`;任何异常 / 空数组 / 超时 → `Optional.empty()`(记 warn 日志)。设置合理超时(connect/read ~3s)。
  - DTO 解析:仅声明需要的字段(`nickname`,`phone`),`@JsonIgnoreProperties(ignoreUnknown=true)` 忽略 reportTo/department 等。
- **缓存** `OnDutyCache`:进程内 `ConcurrentHashMap<scheduleName, (OnDutyPerson, expiresAt)>`,TTL ~10 分钟。`DutyLineService.activeOrdered()` 解析每条 duty line 时:若 `scheduleName` 非空 → 查缓存,miss 则调 `OnDutyClient` 并写缓存;命中外部人 → response 的 `labelZh/labelEn` 保持管理员配置的部门名,`phone` 用外部电话,另加 `dutyName`(值班人姓名)字段;若 `scheduleName` 空或外部返回空 → 用静态 `phone`,`dutyName` 为 null。
  - (TTL 用注入的时间源以便测试;避免在缓存逻辑里直接用 `Instant.now()` 难测——用 `Clock` bean 注入。)
- **`DutyLineResponse`** 加可空 `dutyName`(外部值班人姓名);`scheduleName` 不必下发给门户(可下发也无妨,但门户不展示;admin 需要,故 admin 的 DutyLineResponse 含 `scheduleName`)。
  - 实现注意:portal 与 admin 共用 `DutyLineResponse` 即可,`scheduleName` 字段对门户无害;`dutyName` 仅 portal `activeOrdered()` 解析时填充,admin 列表不填充(或填充亦可)。

### 前端

- `lib/api/dutyLines.ts`:`DutyLine` 类型加 `scheduleName?: string | null`、`dutyName?: string | null`;`DutyLineInput` 加 `scheduleName?: string`。
- `features/dashboard/DutyLinesPanel.vue`:每行展示 `部门 label · (dutyName ? dutyName : —) · phone`。`dutyName` 存在时显示姓名;否则仅 label + phone(静态)。保持紧凑单行。
- `features/admin/duty-lines/DutyLineFormModal.vue`:加 `scheduleName`(排班名称 / Section code)输入,选填,带说明「填写后将从外部值班系统按当日排班拉取值班人电话;留空则使用上方静态电话」。
- `features/admin/security/SecurityAdminView.vue`:新增「值班系统对接」分区——`dutyApiBaseUrl` 输入 + `dutyApiKey` 输入(password 型,占位显示「已配置/未配置」,留空表示不修改);保存并 `reload()`。
- i18n:`admin.dutyLineForm.scheduleNameLabel/Hint`、`admin.security.dutyApiSection/baseUrl/apiKey/apiKeyHint`、`dashboard.dutyLines.*`(如需);zh/en 对齐。
