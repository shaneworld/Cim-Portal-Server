# 图标选择器尺寸修正 + 自定义图标上传 设计

**日期:** 2026-06-11 **状态:** 设计已确认,进入实现计划
**仓库:** 前端 `cim-portal-client`(Vue3/TS/Tailwind v3/reka-ui/vue-i18n)+ 后端 `cim-portal-server`(Oracle/JDK21/Flyway/JPA),分支 `dev`(Oracle-only)。两任务独立,顺序 ①→②,分别提交。

## 已确认决策
- 任务 1 目标:**链接表单里的图标选择器**(非卡片图标)。
- 上传存储:**Oracle BLOB**(新表 `uploaded_icon`)。
- 编码区分:**沿用 `link.icon` 字段约定** —— 内置为 lucide key;上传为 `upload:<id>`。
- 约束:**PNG / JPEG / WebP / SVG,≤ 512KB**。

## 现状(已核对)
- `AppIcon.vue`:`<component :is="iconFor(name)" :stroke-width="2"/>`,自身无尺寸,由父级 class 决定大小。`iconFor` 命中 `map[name]`,否则 `FALLBACK_ICON=LayoutGrid`。`ICON_KEYS` 为 48 个内置 key。
- 选择器(`LinkFormModal.vue` 第 172–176 行):`<div class="grid grid-cols-6 gap-1.5 sm:grid-cols-12">` + 每个按钮 `class="grid aspect-square w-full place-items-center rounded-lg border transition"`,内含 `<AppIcon :name="ic" class="size-4"/>`。问题:`aspect-square w-full` 在 12 列固定栅格下,弹窗变宽(任务②改 `xl`≈60rem)后每个格子被撑到 ~60–70px,中间却是 16px 小图标 —— 显得过大。
- 卡片图标(`SystemCard.vue` 第 30 行):`size-9`(36px)品牌色方块内 `<AppIcon class="size-[18px]"/>`(本任务不动其尺寸,仅让上传图标也能在此渲染)。
- 后端 `Link.icon`:`@Column(nullable=false,length=64)`;`LinkRequest.icon` `@NotBlank`。`upload:<id>` 在 64 长度内。
- 安全:`SecurityConfig` permitAll 含 actuator/health、swagger、api-docs、`/dev/token`、`/api/portal/config`、login;`/api/admin/**` 限 `PORTAL_ADMIN`。
- Flyway oracle 最新 **V7** → 下一个 **V8**;`OracleMigrationTest` 断言 7 → 改 8。

## ① 图标选择器尺寸修正(前端)
`LinkFormModal.vue` 选择器:
- 外层栅格改为固定尺寸自动填充:`grid gap-1.5 [grid-template-columns:repeat(auto-fill,minmax(2.75rem,1fr))]`(替换 `grid-cols-6 sm:grid-cols-12`)。
- 按钮去掉 `aspect-square w-full`,改固定方形 `aspect-square`(在 ~44px 列内自然成 ~44px),其余样式不变。
- 图标 `size-4` → `size-5`(20px),填充更协调。
- 结果:任意弹窗宽度下格子稳定 ~44px 并自动换行铺满,不再被撑大。交付前后对比截图。

## ② 自定义图标上传(后端 + 前端)

### 存储(Flyway V8,oracle)
```sql
CREATE TABLE uploaded_icon (
  id           NUMBER GENERATED BY DEFAULT AS IDENTITY (START WITH 1000),
  content_type VARCHAR2(64)  NOT NULL,
  file_size    NUMBER        NOT NULL,
  bytes        BLOB          NOT NULL,
  created_at   TIMESTAMP     DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT pk_uploaded_icon PRIMARY KEY (id)
);
```

### 后端
- `UploadedIcon` 实体(`bytes` 用 `@Lob byte[]`)+ `UploadedIconRepository`。
- `IconService`:校验 + 保存 + 读取。允许 content-type:`image/png`、`image/jpeg`、`image/webp`、`image/svg+xml`;大小 ≤ 512*1024 字节;否则抛 `ApiException.badRequest`。
- `IconController`:
  - `POST /api/admin/icons`(admin;`@RequestParam("file") MultipartFile`):校验→存→返回 `{ id, ref: "upload:"+id }`(201)。
  - `GET /api/icons/{id}`(**permitAll**):返回 `ResponseEntity<byte[]>`,`Content-Type` 为存储的 content_type,`Cache-Control: public, max-age=86400`;缺失 404。
- `SecurityConfig`:permitAll 增加 `GET /api/icons/**`(`/api/admin/icons` 仍受 `/api/admin/**` 保护,仅 admin)。
- Multipart 上限:`spring.servlet.multipart.max-file-size=1MB`、`max-request-size=1MB`(基础 application.yml;业务再按 512KB 严校)。

### 前端
- `AppIcon.vue`:`name` 以 `upload:` 开头时渲染 `<img :src="'/api/icons/'+id" class="size-full object-contain" alt="">`(尺寸继承父级 class);否则维持 lucide `<component>`。→ 卡片与选择器统一支持上传图标。
- `SystemCard.vue`:当 `link.icon` 为 `upload:*` 时,图标方块不使用 `bg-brand text-white`(改中性底/无底)以正确显示图片;内置 key 维持品牌色方块。
- `LinkFormModal.vue` 选择器:在内置图标网格前/后加一个「上传」磁贴(点选打开文件选择)→ `POST /api/admin/icons` → 成功后 `form.icon = ref`(`upload:<id>`)并把该上传图标作为「已选中」磁贴预览;编辑时若 `form.icon` 为 `upload:*`,渲染其图片为已选。
- API client:`uploadIcon(file): {id, ref}`。i18n:`admin.linkForm.uploadIcon`、错误提示等,zh/en 键对齐。

### 测试
- 后端:上传合法 PNG → 201 且 ref=`upload:<id>`;错误类型 → 400;超 512KB → 400;`GET /api/icons/{id}` 返回字节 + 正确 content-type;缺失 → 404。`OracleMigrationTest` 7→**8**。(`@SpringBootTest`+`OracleIntegrationTest`,`MockMvc` multipart;admin 身份用 `TestJwts`。)
- 前端:`AppIcon` 对 `upload:1` 渲染 `<img>` 且 src=`/api/icons/1`;i18n 键对齐。

### 范围外(YAGNI)
- 孤儿图标回收(链接改图标/删除后未引用的 `uploaded_icon` 行不自动清理)—— 仅注明,不做 GC。
- 图片压缩/缩放/裁剪 —— 前端 `object-contain` 自适应即可。
